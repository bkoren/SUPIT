# Algebra University Website

A student demo website about Algebra University.

📅 Built in 2024 for the *Standards in Applying Internet Technologies* (SUPIT) course at Algebra University.

> **Note:** The login, register and curriculum APIs were hosted by the university and are **no longer online**, so these features don't work anymore.

## Features

- Navigation bar with Login/Logout, About Us, News, Curriculum and Contact
- Login and registration with a JWT token
- Curriculum page for logged-in users: search courses, see course details, and add or remove courses from a table
- Contact form
- Background video, image gallery, modal dialogs and section animations

## Technologies

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/bkoren/SUPIT.git
   ```
2. Go into the project folder and open `index.html` in your browser:
   ```bash
   cd SUPIT.git
   start index.html
   ```
   (`start` works on Windows. You can also just double-click `index.html`.)
